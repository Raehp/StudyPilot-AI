# StudyPilot AI 比赛演示指南（DEMO-GUIDE）

> 5–8 分钟演示流程，基于**真实运行的系统**（真实 MySQL / Redis / DashScope，非 Mock）。
> 演示账号：`demo / demo123456`（uid=1，已预置真实数据）。前端 `http://localhost:5173`（开发）或部署地址。

## 一、演示前检查清单（务必先跑通）

1. 后端 `curl http://localhost:8080/api/health` 返回 `status:"UP"`。
2. 前端可访问，`demo/demo123456` 可登录。
3. 确认预置真实数据存在（demo 账号）：
   - 知识库「深度学习论文库 v2」（id=1），含 **288 个真实向量切片**（文档 20/21/24/25/29，已 Embedding）。
   - 已有 RAG 会话（如「这篇论文的主要研究内容是什么？」）。
   - 测验「联邦学习 智能测验」（已提交，得分 80）。
   - 学习计划与任务若干。
4. 工作台统计真实非零：知识库 2 / 论文文档 15 / 已解析 13 / 已向量化 5 / 问答会话 2 / 学习计划 4 / 已完成任务 1 / 练习次数 4。
5. DashScope Key 有效、外网可达（AI 分析/出题/问答为真实调用，需预留等待时间）。
6. 建议演示前将主题切到**浅色**、浏览器全屏、关闭无关标签页。

> 说明：预置库中部分文档标题为开发期测试名（paper/medium 等），但切片内容与向量均为真实解析 Embedding 结果，RAG/检索/出题基于真实内容。如需更观感，可提前上传一篇命名规范的真实论文 PDF 并完成解析+向量化作为主演示文档。

## 二、演示主线（约 7 分钟，预置数据快速路径）

### 0:00–0:40 · 开场 + 工作台真实统计
- 登录 demo → 工作台。
- 讲解：一站式学习科研工作台；**所有统计来自真实 MySQL，无模拟数据**，无记录显示 0/诚实空状态。
- 指出 9 项真实计数与 ECharts 图表（上传趋势/学习进度/成绩分布/题型分布）。
- 亮点：明暗主题切换（点右上角主题按钮，即时生效并持久化）。

### 0:40–1:40 · 科研知识库 + 文档解析
- 进入「科研知识库」→ 打开「深度学习论文库 v2」。
- 展示文档列表、解析状态（READY）、页数/字符数。
- 打开一篇已解析文档查看**保留页码的全文**。
- 讲解：PDF 上传四重安全校验 + UUID 重命名 + PDFBox 异步解析。
- （可选现场上传一篇小 PDF，展示解析状态轮询；解析通常数秒内完成。）

### 1:40–2:40 · AI 论文分析
- 进入「论文阅读」→ 选择已解析论文 → 触发/查看 AI 分析。
- 展示 qwen-plus 生成的**摘要 + 12 项结构化分析**（研究问题/方法/创新点/结论/局限性等）。
- 讲解：真实通义千问调用，结果持久化（biz_paper_analysis），分段分析支持长文。
- 注意：若现场触发新分析，AI 需数十秒，可先展示已生成的结果，口述异步流程。

### 2:40–3:20 · 向量化 + 语义检索
- 在知识库展示文档**向量化状态**（SUCCESS，切片数/向量数）。
- 演示语义检索：输入如「联邦学习通信优化」→ 返回 Top-K 切片 + 相似度分数 + 页码溯源。
- 讲解：text-embedding-v3（1024 维）→ MySQL JSON 存储 → 按用户+知识库范围 JVM 余弦检索（刻意不引入向量数据库）。

### 3:20–4:50 · RAG 智能问答（核心亮点）
- 进入「AI 智能问答」→ 选择知识库会话 → 提问，如「这篇论文的主要研究内容是什么？」或「请综述研究背景、方法、实验设计与结论」。
- 展示 **SSE 流式输出**（逐字生成）+ **引用溯源**（点击引用查看原文片段/页码/相似度）。
- 讲解：检索增强生成，答案附带真实文档引用，可多轮追问；Prompt 注入隔离规则保障安全。
- 真实预期：流式数百字答案 + 多条引用（联调实测答案约 490 字、4 条引用）。

### 4:50–5:50 · 学习计划 + 任务打卡
- 进入「学习计划」→ 打开一个计划 → 展示 AI 生成的**逐日任务清单**（阶段/重点/推荐内容/时长）。
- 现场勾选完成一个任务 → **进度实时重算**。
- 讲解：qwen-plus 生成计划（可结合知识库检索），任务打卡与进度追踪，输出结构化校验。

### 5:50–6:50 · 智能出题 + 在线练习 + 判分
- 进入「智能出题」→ 打开「联邦学习 智能测验」（已提交，得分 80）查看成绩与解析。
- 或现场「AI 出题」：选知识库 + 题型/难度/题数 → 生成单选/多选/判断/简答。
- 在线作答 → 提交 → **客观题自动判分 + 简答题 AI 判分** → 查看得分/解析/错题回顾。
- 讲解：基于知识库真实内容出题，练习态隐藏答案，简答 AI 评分依据可解释。
- 注意：现场出题+判分为真实 AI 调用，需预留等待；可先展示已提交测验。

### 6:50–7:30 · 回看工作台 + 收尾
- 回到工作台，指出统计随操作真实变化。
- 简述技术栈与安全（JWT 单会话/数据隔离/限流/上传校验/密钥仅后端）。
- 收尾：M1–M7 全链路真实交付，176 项自动化断言通过，Docker 一键部署。

## 三、现场全链路路径（可选，时间充裕时）

若评委要求从零演示完整链路，按以下顺序（每步真实落库，AI 步骤需等待）：
注册新账号 → 创建知识库 → 上传 PDF → 解析 → AI 分析 → 向量化 → 语义检索 → 新建会话 RAG 问答（看引用）→ 创建学习计划 → AI 生成 → 完成任务 → AI 出题 → 在线练习 → 提交看成绩 → 工作台统计反映新数据。
> 该链路已被 `m7-integration-test.mjs` 真实验证（33/33）：解析 3749 字符、12 字段分析、16 切片 Embedding、SSE 7078 字节、RAG 490 字 + 4 引用、计划 7 任务、测验得分 67。

## 四、时间控制与降级预案

- AI 调用真实耗时：论文分析数十秒、出题/计划生成数十秒、RAG 流式数秒~数十秒。**优先展示已生成的真实结果**，现场触发作为加分项，避免冷场。
- 若 AI 服务超时/限流：展示已持久化结果 + 口述异步状态机；系统对超时/429 有友好提示与状态回滚，不会崩溃。
- 若需重置演示：用 demo 预置数据即可，无需清库（**严禁 FLUSHALL 共享 Redis**）。
- 单会话提示：演示中避免在另一浏览器重复登录 demo（会使当前令牌失效）。
